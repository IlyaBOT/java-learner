# Java / лаборатория

Интерактивный курс Java с нуля для себя. [открыть сайт](https://ilyabot.github.io/java-learner/) · [главы и решения](work/) · [настройка ОС](SETUP.md) · [проверки](../../actions).

## Что внутри

- 12 глав, 24 урока, 36 упражнений (легко / средне / сложно), 12 мини-экзаменов по 4 вопроса; проходной балл — 3/4.
- Отдельная настройка для Windows XP/7/10/11, Linux, Mac OS X Intel и современной macOS Apple Silicon. На старых ОС используй исторические совместимые JDK, не сегодняшние установщики.
- Сайт хранит отметки, черновики и результаты экзаменов **только в браузере** (`localStorage`). JSON можно экспортировать/импортировать. Он не запускает произвольный Java-код и не запрашивает GitHub-токен.
- По одному Java-файлу для основного задания каждой главы в `work/ch00` … `work/ch11`. Скрипты проверяют готовые решения; `// TODO:` означает «ещё в работе», а не успешное прохождение. Ответы к личным работам не подставляются автоматически.

## Быстрый старт

1. Подбери JDK и среду по [SETUP.md](SETUP.md). Для современной машины удобен JDK 21 или 25. Проверь `java -version` и `javac -version`.
2. Клонируй `git clone https://github.com/IlyaBOT/java-learner.git` и открой проект в IDE. Сайт также можно открыть локально через `python -m http.server 8000 -d docs` и `http://localhost:8000/` (или через опубликованный адрес). Для ES-модулей не открывай `docs/index.html` через `file://`.
3. Пройди главу, сделай задание в `work/chXX/`, **убери комментарий `// TODO:`** и проверь работу:

   ```bash
   bash scripts/check.sh
   ```

   В Windows PowerShell без Git Bash:

   ```powershell
   pwsh -File scripts/check.ps1
   # В Windows PowerShell 5.1: .\scripts\check.ps1
   ```

4. Коммить решение: `git add work/ch00/HelloEnvironment.java` → `git commit -m "Глава 00: javac наконец-то увидел меня"` → `git push`. В [Actions](../../actions) найдёшь результат проверки. По аналогии выкладывай отчёты, скриншоты и заметки в `results/chXX/`.

При компиляции готовых работ проверки разбирают **все** исходники. Если неверный Java-код оставлен в другом файле, сборка упадёт даже если там ещё `// TODO:`. Не трогай файлы будущих работ, пока не готов их компилировать.

## Прогресс и Git

Отметки на сайте не синхронизируются с GitHub: статический GitHub Pages не имеет личного сервера и не хранит авторизацию. Экспортируй `java-learner-progress.json` из обзора и при желании коммить его в `results/` (помни: репозиторий публичен). Импорт **заменяет** текущие отметки и черновики браузера; скачай резервную копию перед импортом.

Старайся фиксировать изменения по одной главе или работающему этапу, а не одним огромным коммитом. Сообщения могут быть смешными и матерными, главное — чтобы по ним было ясно, что именно изменилось.

## Разработка сайта

Сайт — обычные HTML/CSS/JS в `docs/`, без npm-пакетов и стороннего Java backend. `npm test` проверяет структуру курса, экзамены и формат прогресса. Workflow `.github/workflows/course.yml` запускает эти проверки и Java-лабораторные на push/PR, затем публикует `docs/` на GitHub Pages при push в `main`. Для первоначальной публикации один раз выбери **Settings → Pages → Build and deployment → GitHub Actions**. Никакие секреты для Pages не требуются.
