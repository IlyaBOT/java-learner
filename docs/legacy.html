Установка Java и среды разработки

Выбери свою платформу. Команды проверки показаны внутри каждого раздела; java и javac должны находиться и иметь согласованные версии. Подробная таблица и источники есть в SETUP.md.

Windows 10 / 11 · основной маршрут

  1. Установи Temurin JDK 25 LTS для Windows x64. Через PowerShell можно: winget install EclipseAdoptium.Temurin.25.JDK. После установки открой новый терминал.
  2. Поставь IntelliJ IDEA Community (бесплатная версия), создай New Project → Java, выбери установленный JDK. JDK внутри самой IDE для запуска IDE не заменяет project SDK.
  3. Проверь в PowerShell java -version, javac -version, where.exe java. Если версии разные, исправь PATH и JAVA_HOME, открой новый терминал.
javac -encoding UTF-8 Hello.java
java Hello

Для работ из репозитория: git clone https://github.com/IlyaBOT/java-learner.git, затем в PowerShell bash scripts/check.sh через Git Bash или используй pwsh -File scripts/check.ps1.

Windows XP / 7 · историческая ветка

  1. XP: бери исторический JDK 6 для своей архитектуры из доверенного архива правообладателя. Современный Temurin здесь не предназначен для запуска. Начни с javac и java в cmd.exe, редактором может быть обычный текстовый редактор с сохранением в UTF-8.
  2. Windows 7: исторический JDK 8 x86/x64 и подходящая старая версия IDE возможны, но совместимость проверяй для конкретного билда. Если IDE тяжела, используй редактор + cmd.exe. Новые релизы IDE и JDK не обещают поддержку Windows 7.
  3. Добавь папку bin конкретного JDK в PATH. Проверь where java, java -version, javac -version.
javac -encoding UTF-8 Hello.java
java Hello

На XP русская консоль может испортить вывод; для первых лабораторных выбран ASCII. Главы 0–5 намеренно обходятся без новых конструкций, но CI компилирует их под Java 8, поэтому запуск на JDK 6 всё равно нужно отдельно проверить. Старую Java не используй для просмотра непроверенных сайтов или запуска чужих JAR.

Linux · пакеты и терминал

  1. Установи JDK из репозитория дистрибутива: например, для Debian/Ubuntu при наличии пакета sudo apt update && sudo apt install openjdk-21-jdk git; для Arch sudo pacman -S jdk21-openjdk git. Или возьми актуальный Temurin 25 для своей архитектуры.
  2. Проверь java -version, javac -version, readlink -f "$(command -v javac)". При нескольких JDK переключай их средствами дистрибутива и проверяй обе команды.
  3. Выбери IntelliJ IDEA Community либо VS Code с Java Extension Pack. Открой корень этого репозитория, а не папку отдельного класса.
git clone https://github.com/IlyaBOT/java-learner.git
cd java-learner
bash scripts/check.sh

Если пакет openjdk-21-jdk отсутствует, проверь версию дистрибутива и список его пакетов, не добавляй случайные сторонние репозитории.

Mac OS X Intel · Leopard / Snow Leopard / Lion

  1. 10.5.8 Leopard: обнови системную Java через Apple Software Update (существует Java for Mac OS X 10.5 Update 10). На 64-битном Intel проверь наличие Java 6 и javac; на конкретной машине доступная версия может быть другой. Oracle JDK 7 требует минимум 10.7.3.
  2. 10.6 Snow Leopard: используй Apple Java 6 и установи доступное Java for Mac OS X 10.6 Update 17. Проверь java -version и javac -version в Terminal. Установка только JRE без компилятора для упражнений не подходит.
  3. 10.7.3+ Lion: Oracle JDK 7 выпускался для Intel Mac с 10.7.3; для 10.8+ выпускался JDK 8. Подбирай исторический совместимый установщик и проверяй требования именно выбранного обновления, а не сегодняшнего JDK с тем же номером версии.
  4. На 10.5/10.6 начни с Terminal и текстового редактора/Xcode того времени; современные IntelliJ IDEA и VS Code на этих системах не запускаются. На новом компьютере можно редактировать тот же Git-репозиторий.
/usr/libexec/java_home -V
java -version
javac -version
javac -encoding UTF-8 Hello.java && java Hello

Главы 0–5 — разумный маршрут для Apple Java 6; при Java 5 возможны отличия даже в базовых API. Java 7 добавляет try-with-resources, Java 8 — лямбды и Stream API. Работы старше установленной Java можно отправлять в GitHub и проверять CI.

macOS Apple Silicon · M-серия

  1. Скачай Temurin JDK 25 LTS для macOS aarch64 и установи PKG. Вариант JDK 21 LTS тоже подходит для этого курса.
  2. В Terminal проверь /usr/libexec/java_home -V, java -version, javac -version. При нескольких версиях выбери одну явно: export JAVA_HOME=$(/usr/libexec/java_home -v 25), затем export PATH="$JAVA_HOME/bin:$PATH".
  3. Установи IntelliJ IDEA Community для Apple Silicon, открой репозиторий и выбери project SDK.

00 · Рабочее место

От установки JDK до первой программы без магии кнопки Run. Время: 35 мин.

Цели

  • Отличать JDK, JVM и IDE
  • Проверять PATH и версию компилятора
  • Собрать и запустить класс вручную

Урок 1. Три разных роли

JDK содержит инструменты разработки, включая javac. JVM исполняет байткод из файлов .class. IDE редактирует исходники и запускает инструменты, но не заменяет выбор JDK для проекта.

Hello.java  →  javac  →  Hello.class  →  java / JVM  →  вывод

Имя публичного класса и файла должны совпадать: public class Hello хранится в Hello.java. Компиляция и запуск — два отдельных шага. Ошибка 'javac' is not recognized означает проблему с установленным JDK или PATH, а не с исходным кодом.

Урок 2. Первый запуск и диагностика

Создай файл Hello.java в пустой папке. На Windows используй PowerShell/cmd, на Unix — Terminal. Запусти команды из той же папки, где лежит файл.

public class Hello {
    public static void main(String[] args) {
        System.out.println("JAVA_READY");
    }
}
javac Hello.java
java Hello

java Hello принимает имя класса, а не Hello.class. Если версия языка в IDE отличается от терминала, проверь project SDK, PATH и JAVA_HOME. Напиши java -version и javac -version в заметках к занятию.

01 · Как Java исполняется

Исходник, байткод, main, аргументы и диагностика. Время: 40 мин.

Цели

  • Найти точку входа
  • Передать аргументы из терминала
  • Различать ошибки компиляции и выполнения

Урок 1. Метод main и аргументы

JVM начинает обычную консольную программу с public static void main(String[] args). Массив args содержит строки после имени класса. При вызове java Echo one two в нём две строки: "one" и "two".

public class Echo {
    public static void main(String[] args) {
        System.out.println(args.length);
        if (args.length > 0) {
            System.out.println(args[0]);
        }
    }
}

Обращаться к args[0] без проверки длины опасно: получишь ArrayIndexOutOfBoundsException во время выполнения.

Урок 2. Что именно ломается

Синтаксическая ошибка, например пропущенная ;, остановит javac: новой версии .class не будет. Ошибка выполнения случается после старта JVM: массив вышел за границы, число не удалось разобрать, файл отсутствует.

Старый .class может остаться после неудачной компиляции. Удаляй его при диагностике, а затем запускай команды снова. java -cp . Echo задаёт classpath текущей папкой явно. В IDE сначала посмотри команду запуска и рабочую директорию.

02 · Данные и ветвления

Типы, арифметика, сравнение и управляющие конструкции. Время: 55 мин.

Цели

  • Выбрать примитивный тип
  • Разобрать if/else и цикл
  • Учесть границы и целочисленное деление

Урок 1. Значения, ссылки и операции

int хранит целые числа, double — числа с плавающей точкой, boolean — истину/ложь, char — символ. String — объект. Выражение 5 / 2 даёт 2, потому что оба операнда целые; 5.0 / 2 даёт 2.5.

int age = 18;
boolean adult = age >= 18;
String name = "Ilya";
System.out.println(name + ": " + adult);

Для содержимого строк используй a.equals(b), а == проверяет, указывают ли ссылки на один объект. null не является пустой строкой.

Урок 2. Условия и циклы

if/else if/else выбирает одну ветку. Порядок условий имеет значение: сначала специальные случаи, затем общие. Цикл for удобен, когда число итераций известно; while — когда известно условие окончания.

for (int i = 0; i < 3; i++) {
    if (i % 2 == 0) {
        System.out.println(i);
    }
}

Проверь граничные значения: 0, переходы между диапазонами, отрицательные входы. Ошибки на границе < и <= чаще ошибок внутри диапазона.

03 · Методы и массивы

Делим код на части и работаем с последовательностями. Время: 55 мин.

Цели

  • Написать метод с параметрами
  • Итерироваться по массиву
  • Определить поведение пустого входа

Урок 1. Метод как контракт

Метод принимает параметры, делает одну понятную работу и возвращает значение либо объявляет void. static означает вызов без экземпляра класса. Возвращаемое значение стоит проверять отдельно от вывода в консоль.

public static int square(int x) {
    return x * x;
}
int result = square(4); // 16

Контракт включает граничные случаи. Для максимума пустого массива можно бросить IllegalArgumentException; для суммы пустого массива естественен ноль.

Урок 2. Индексы и обход

Индексы массива начинаются с нуля; последний индекс равен array.length - 1. length — поле, без скобок. Для чтения каждого элемента подходит enhanced for:

int[] values = {3, 5, 8};
int sum = 0;
for (int value : values) {
    sum += value;
}

Массив имеет фиксированную длину. Если нужно наращивать количество элементов, позже пригодится ArrayList.

04 · Объекты и инварианты

Урок 1. Класс и объект

Класс описывает данные и действия, объект — конкретный экземпляр. Поля разных объектов независимы; поле с static общее для класса. Конструктор задаёт исходное корректное состояние.

private скрывает поле от внешнего кода. Внешний код должен пользоваться методами, которые проверяют правила.

public void deposit(int amount) {
    if (amount <= 0) throw new IllegalArgumentException();
    balance += amount;
}

Можно использовать наследование для отношений «является», но для просто связанного поведения обычно понятнее композиция. Здесь хватит одного класса с ясными правилами.

09 · Потоки и задачи

Разделение работы, гонки данных и завершение ExecutorService. Время: 75 мин.

Цели

  • Собрать независимые результаты
  • Всегда завершать executor

Урок 1. Конкурентность не равна ускорению

Несколько потоков могут выполняться вперемешку. Операция counter++ не атомарна: чтение, увеличение и запись могут пересечься. Локальные суммы по независимым частям массива не требуют общего изменяемого счётчика.

ExecutorService pool = Executors.newFixedThreadPool(2);
try {
    Future<Long> left = pool.submit(() -> 42L);
    System.out.println(left.get());
} finally {
    pool.shutdown();
}

Потоки создают накладные расходы; для малого массива последовательный цикл обычно проще и быстрее.

Урок 2. Будь честен с ошибками

Future.get() ждёт результат и передаёт сбой задачи через ExecutionException. Если поток прерван, сохрани флаг прерывания, если решил перехватить InterruptedException. Не оставляй executor жить после завершения программы.

Разбей данные на части, считай локально и сложи long-результаты. int может переполниться ещё до преобразования в long, поэтому аккумулятор с самого начала должен быть long.

10 · HTTP и данные

URL, кодирование параметров и граница между строкой и протоколом. Время: 75 мин.

Цели

  • Кодировать query-параметры
  • Отличать сетевую ошибку от HTTP-ответа
  • Понимать назначение JSON

Урок 1. URL нельзя собирать простым плюсом

Строка q=hello world не является корректно закодированным query-параметром. URLEncoder.encode(value, "UTF-8") превращает пробел в + для form/query encoding, символ & — в %26. Каждый ключ и значение кодируются по отдельности.

String query = "q=" + URLEncoder.encode("a & b", "UTF-8");
// q=a+%26+b

Не кодируй целый URL целиком: слеши, двоеточие и знаки вопроса имеют структурную роль.

Урок 2. Слои ошибки и JSON

HTTP-ответ 404 означает, что сервер ответил, но не нашёл ресурс. Таймаут или сбой DNS означают, что ожидаемого HTTP-ответа вообще не было. JSON описывает данные: объект, массив, строка, число, boolean, null; он не равен Java-объекту сам по себе.

На реальном проекте используй проверенную библиотеку JSON, а сетевые вызовы делай с таймаутами и обработкой статуса. В этом задании кодируется только query-строка; сеть не требуется, поэтому проверка воспроизводима в CI.

Урок 1. Проектируй контракт CLI

Программа получает путь файла и команду: add, list, done. Сначала определи формат строк и поведение для ошибочных аргументов. Сохраняй простые задачи как id|done|text, где в тексте символы | и перевод строки запрещены. При list порядок — по ID.
